# Bài 2: Khởi tạo User thường và thiết lập đặc quyền quản trị (Sudoers Configuration)

## 1. Mục tiêu

* Tạo tài khoản người dùng `devops` trên Ubuntu Server để hạn chế sử dụng trực tiếp tài khoản `root`.
* Cấp quyền quản trị cho `devops` thông qua nhóm `sudo`.
* Sao chép SSH Key từ `root` sang `devops` để cho phép đăng nhập từ xa.
* Thiết lập quyền truy cập phù hợp cho thư mục `.ssh` và file `authorized_keys`.
* Kiểm tra khả năng đăng nhập SSH và thực thi lệnh sudo.

## 2. Các bước thực hiện

### Bước 1: Tạo user devops

Sử dụng tài khoản root để tạo người dùng mới:

```bash
adduser devops
```

Nhập mật khẩu và các thông tin cần thiết theo yêu cầu của hệ thống.

Kiểm tra thông tin user:

```bash
id devops
```

### Bước 2: Thêm devops vào nhóm sudo

Cấp quyền quản trị cho user `devops`:

```bash
usermod -aG sudo devops
```

Kiểm tra nhóm của user:

```bash
groups devops
```

Kết quả cần có nhóm `sudo`.

### Bước 3: Sao chép SSH Key

Sao chép cấu hình SSH từ thư mục của root sang thư mục home của user `devops`:

```bash
rsync --archive --chown=devops:devops /root/.ssh /home/devops/
```

Lệnh này giúp sao chép thư mục `.ssh` và thiết lập quyền sở hữu cho user `devops`.

### Bước 4: Phân quyền thư mục và file SSH

Thiết lập quyền truy cập cho thư mục `.ssh`:

```bash
chmod 700 /home/devops/.ssh
```

Thiết lập quyền truy cập cho file `authorized_keys`:

```bash
chmod 600 /home/devops/.ssh/authorized_keys
```

Đảm bảo user `devops` sở hữu các file và thư mục SSH:

```bash
chown -R devops:devops /home/devops/.ssh
```

### Bước 5: Kiểm tra cấu hình

Kiểm tra quyền sở hữu và phân quyền:

```bash
ls -la /home/devops/.ssh
```

Kiểm tra cấu hình nhóm sudo:

```bash
id devops
```

## 3. Kiểm tra kết quả

### Bước 1: Đăng nhập SSH từ máy cá nhân

Sử dụng lệnh sau để đăng nhập vào Droplet bằng user `devops`:

```bash
ssh -i /path/to/private_key devops@<IP_ADDRESS_DROPLET>
```

Sau khi đăng nhập thành công, kiểm tra tài khoản hiện tại:

```bash
whoami
```

Kết quả:

```text
devops
```

### Bước 2: Kiểm tra quyền sudo

Thực hiện lệnh:

```bash
sudo whoami
```

Nhập mật khẩu của user `devops` nếu hệ thống yêu cầu.

Kết quả:

```text
root
```

Điều này chứng minh user `devops` đã được cấp quyền quản trị và có thể thực thi lệnh với quyền root thông qua sudo.

## 4. Kết quả đạt được

* Đã tạo tài khoản người dùng thường `devops`.
* Đã thêm `devops` vào nhóm quản trị `sudo`.
* Đã sao chép cấu hình SSH Key từ tài khoản root sang tài khoản `devops`.
* Đã thiết lập quyền truy cập phù hợp cho thư mục `.ssh` và file `authorized_keys`.
* Đã kiểm tra đăng nhập SSH và thực thi lệnh `sudo whoami`.

## 5. Log Terminal

### Tạo user và cấp quyền

```text
root@ubuntu:~# adduser devops
root@ubuntu:~# usermod -aG sudo devops
root@ubuntu:~# groups devops
devops : devops sudo
```

### Sao chép SSH Key và phân quyền

```text
root@ubuntu:~# rsync --archive --chown=devops:devops /root/.ssh /home/devops/
root@ubuntu:~# chmod 700 /home/devops/.ssh
root@ubuntu:~# chmod 600 /home/devops/.ssh/authorized_keys
root@ubuntu:~# chown -R devops:devops /home/devops/.ssh
```

### Kiểm tra sudo

```text
devops@ubuntu:~$ sudo whoami
[sudo] password for devops:
root
```
